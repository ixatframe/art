# iArt (1926) — Personal Profile

Static personal profile site. Open `index.html` locally or publish the folder with GitHub Pages.

- Personal profile layout (no ArtBots/admin/developer branding)
- Responsive layout and subtle red animations
- Portrait stored locally in `assets/profile.jpg`
- Contact link points to the XAT forum messenger


The hero portrait uses assets/profile-frame.jpg, featuring the red crown frame. The frame glow and portrait float are animated with CSS. The original assets/profile.jpg is preserved.
